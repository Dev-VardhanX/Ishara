# Ishara design system: claymorphism (Member C owns, B and C use)

Soft, rounded, puffy shapes: large radius, two outer shadows (dark bottom-right, light top-left),
inner shadow on pressed items and inputs, pastel colours, rounded friendly font (Nunito).

Accessibility: text at least 4.5:1 contrast, dark text on pastel buttons, a high-contrast option.

Files: `tokens.json` (source of truth), `tokens.css` (web). Android: copy values into the Compose ClayTheme.
